# Required image assets

Place the approved launch assets in this folder using these exact names:

- `martha-skin-studio-logo.png` — approved horizontal logo artwork
- `favicon.png` — approved square browser icon and Apple touch icon
- `hero-skincare.jpg` — premium landscape skincare image, ideally at least 1200 × 900
- `martha-portrait.jpg` — approved portrait of Martha, ideally at least 800 × 1000

The website intentionally does not include invented substitute artwork. Optimize all files for the web before launch.
